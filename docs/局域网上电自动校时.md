# 局域网上电自动校时

香橙派通过 `192.168.137.1` 向 Windows 电脑取得时间，使用系统自带的 `systemd-timesyncd`。电脑使用 Windows Time 的 NTP 服务，只为香橙派 `192.168.137.2` 配置入站 UDP 123 防火墙放行。该链路使用现有有线连接，独立于校园网和手机热点地址。

香橙派上电后自动启动时间同步；电脑或网线晚于香橙派就绪时，服务继续重试。正常轮询间隔为 32～64 秒。电脑需要开机且有线连接可用；电脑自身时间的准确性决定香橙派的时间准确性。两端保留现有时区，NTP 传输使用 UTC。

Windows 在使用本机时钟时可声明约 10 秒的时间源不确定度；板端根距离上限设为 20 秒以接受这一局域网时间源。这个上限是协议接纳条件，校准后的实际偏差另行测量。Windows Time 使用现有上游配置，并被配置为持续向局域网提供本机时间。

## 一次性安装

先把 `deploy/enable_lan_time_board.sh` 放到板端 `/home/HwHiAiUser/projects/dnb26-smart-home/shared/time-sync/`。然后在本机以管理员身份打开 PowerShell，运行：

```powershell
& 'D:\Codework\dnb26-smart-home\deploy\enable_lan_time_windows.ps1'
```

脚本启用 Windows Time 的 NTP 服务和自动启动，保留电脑原有上游时间服务器配置，增加仅允许指定板端地址、指定有线接口的防火墙规则，然后通过既有 SSH 别名执行板端安装。板端 sudo 密码只在终端交互输入。

Windows 原设置记录在 `output/acceptance/time-sync/windows-before.json`；Windows 启用结果记录在同目录 `windows-after.json`。板端原 NTP 启用状态记录在 `/var/lib/dnb26-time-setup/before.txt`。专用同名配置存在且内容不同时，安装脚本停止，保留已有配置。

## 核验与回退

板端执行 `timedatectl status` 应显示 `System clock synchronized: yes`、`NTP service: active`；`timedatectl timesync-status` 应显示服务器 `192.168.137.1`。安装成功条件还要求本次时间服务已收到并接受该服务器的有效 NTP 响应，避免沿用旧同步标记；结果记录在 `/var/lib/dnb26-time-setup/after.txt`。服务启用状态与一次启动同步可由软件核验；实际断电冷启动结果需要另记，不能由服务重启代替。

时间校准只影响之后的系统时间和新记录。已有历史记录保留原时间。

如需回退，在管理员 PowerShell 中依据 `windows-before.json` 恢复 `NtpServer/Enabled`、`Config/AnnounceFlags` 及 Windows Time 启动/运行状态；仅当原先不存在该规则时移除 `DnB26-LAN-NTP-OrangePi`。板端移除本次专用的 `/etc/systemd/timesyncd.conf.d/70-dnb26-lan.conf`，按 `before.txt` 恢复 NTP 启用状态。应用版本的回退独立于时间服务配置。
