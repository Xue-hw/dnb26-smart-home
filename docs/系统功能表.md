# 智能家居系统功能表

| 功能模块 | 主要功能 |
| --- | --- |
| 系统架构与部署 | 香橙派运行后端、数据库和视觉推理；双 Arduino UNO 负责传感器采集与执行器控制，电脑通过 USB 网关转发命令和状态。 |
| 电脑网页与 Android APK | 提供设备总览、监控识别、历史统计、授权人员管理、系统报警及接口测试页面。 |
| 双端状态同步 | 电脑与手机共用后端和数据库，同步设备状态、控制结果、历史数据及报警信息。 |
| 温湿度与光照监测 | 实时显示温度、湿度、光照原始值及采样时间，并保存历史数据。 |
| 风扇自动温控 | 根据温度阈值自动启停风扇，支持阈值设置与同步、手动启停、速度调节及恢复自动模式。 |
| 灯光控制 | 支持远程开关、亮度调节、RGB 颜色设置、启用灯珠数量设置及基于光照的自动亮度控制。 |
| 入户门与车库门控制 | 支持远程开关、执行器状态显示及约 5 秒自动关闭；车库门移动期间限制重复操作。 |
| RFID 门禁 | 有效读卡成功后开门，读取失败时拒绝；提供蜂鸣提示并同步刷卡事件，日志和界面不显示卡号。 |
| 键盘密码与密码配置 | 提供键盘密码输入、错误拒绝、清除输入、远程修改四位 PIN 及 EEPROM 持久保存功能。 |
| 语音控制 | 通过 ASRPRO 控制门、灯和风扇；支持远程启用或禁用语音控制，临时控制约 5 秒后恢复先前模式与设置。 |
| 实时视频与拍照 | 单路摄像头为物体识别和人脸识别共享实时输入，支持实时预览、抓拍、本地保存及归档照片查看。 |
| YOLO 物体识别 | 通用模型识别人、车等类别，专用模型识别无人机、灭火器和灯泡；支持照片上传和实时识别，显示类别、识别框及置信度。 |
| 灯泡识别联动 | 摄像头识别到灯泡后控制主灯，设置青色常亮及 80% 亮度，并保持灯珠数量；上传照片仅进行识别。 |
| 授权人员管理 | 存储人员信息和人脸照片，提取人脸特征，支持新增、修改、停用人员及查询录入、特征有效性和识别载入状态。 |
| 人脸识别与眨眼核验 | 匹配授权身份，通过实时眨眼核验后申请开门；静态照片仅核对身份，不授予通行资格。 |
| 数据库与历史统计 | 使用 MySQL 存储人员、传感器数据、设备事件、控制回执和识别记录，提供时间筛选、历史查询及统计图表。 |
| 设备状态与故障报警 | 显示板卡、摄像头、模型和数据库状态，支持掉线提示、所属设备控制禁用、报警确认及故障恢复记录。 |
| 管理员权限与安全控制 | 对设备控制、配置修改及人员管理实施写权限校验，支持记住本设备管理员权限、退出权限及敏感信息保护。 |
| 3D 家居可视化 | 提供可旋转、缩放和切换视角的房屋模拟视图，根据设备反馈更新门、灯和风扇状态，并明确显示未知状态。 |
