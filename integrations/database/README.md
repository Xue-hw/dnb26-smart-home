# MySQL 数据库交付

该目录是组员提供的 MySQL 版数据库实现，数据库名为 `smarthome_db`，包含设备当前状态、系统历史日志、授权人员和安防视觉日志四张表。

## 文件

- `smarthome_setup_v2.sql`：建库、建表和演示初始数据脚本。
- `db_helper_mysql_v2.py`：基于 `pymysql` 的读写工具函数。
- `run_test_v2.py`：连接真实 MySQL 后运行的 6 项流程自检。
- `数据库搭建指南_v2.md`：原始安装与使用说明。

代码中的数据库密码是占位文本，部署前应通过环境变量或本机配置注入，不能写入真实凭据。当前实现依赖正在运行的 MySQL 服务，与仓库原先面向 Orange Pi 的 SQLite 规划尚未统一，后续整合时需要做方案决策。
