# 数据库搭建指南 v2（智能家居 IoT）

> v2 更新点：补上老师题目里明确要求的 **授权人员管理表（authorized_users）** 和 **前端查询接口**（实时状态 + 时间区间历史检索），旧版只有 3 张表 2 个函数，验收会缺项。

## 1. 安装 Python 驱动

```bash
pip install pymysql
```

## 2. 一键建库建表

打开本地 MySQL 命令行，执行 `smarthome_setup_v2.sql` 里的全部内容（或直接 `mysql -u root -p < smarthome_setup_v2.sql`）。

共 **4 张表**，对应老师要求：

| 表 | 对应题目要求 |
|---|---|
| `device_current_status` | GUI 实时展示设备状态；远程控制的写入目标 |
| `system_history_logs` | 按时间区间检索温度/灯/门窗历史数据（带联合索引） |
| `authorized_users` ⭐新增 | 存储和管理授权人员信息（用户名/人脸特征路径/PIN 码/启用状态） |
| `security_vision_logs` | YOLO + 人脸识别「2真1假」事件日志，答辩溯源 |

## 3. 改数据库密码

记事本打开 `db_helper_mysql_v2.py`，把第 21 行附近 `'password': '密码'` 改成你本地 MySQL 密码，Ctrl+S 保存。

## 4. 各方向调用方式

**硬件同学（数据上报）**：
```python
from db_helper_mysql_v2 import update_device_and_log
update_device_and_log('thermometer_1', 'temperature', 28.5)   # 数值型
update_device_and_log('front_door', 'door_state', 'open')     # 状态型
```

**GUI 同学（前端展示）**：
```python
from db_helper_mysql_v2 import get_all_device_status, get_historical_data, list_authorized_users, get_security_logs
get_all_device_status()                                        # 实时状态面板
get_historical_data('temperature', '2026-07-06 08:00:00', '2026-07-06 12:00:00')  # 折线图
list_authorized_users()                                        # 人员管理页
get_security_logs(20)                                          # 安防记录页
```

**GUI 远程控制（挑战项）**：直接复用 `update_device_and_log('exhaust_fan', 'fan', 'on')` 即可。

**智科算法同学（2真1假）**：
```python
from db_helper_mysql_v2 import log_security_event, verify_pin
log_security_event('static/captures/xxx.jpg', 'person', 'true_1_pass', 'gate_opened')
verify_pin('123456')   # PIN 备用验证，通过返回用户名，失败返回 None
```

**人员管理**：
```python
from db_helper_mysql_v2 import add_authorized_user, set_user_active
add_authorized_user('zhangsan', 'static/faces/zhangsan.pkl', '666666')
set_user_active('zhangsan', 0)   # 禁用
```
