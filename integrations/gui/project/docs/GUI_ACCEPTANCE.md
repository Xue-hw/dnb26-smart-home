# GUI v1.1.0 检查记录

日期：2026-11-13

## 已通过

- TypeScript 类型检查：npm run typecheck。
- ESLint：npm run lint。
- 正式静态构建：npm run build，输出 dist。
- 交互回归：npm test，使用 JSDOM 和模拟 HTTP 响应运行实际 React 页面。

7组回归覆盖：
1. acked 命令成功；缺失门窗数据不显示关闭；真实模式不显示演示模式。
2. failed 命令不显示成功。
3. timeout 命令不显示成功。
4. pending 命令经过 GET 命令状态接口获取 acked 后才显示成功。
5. 历史页编辑时间不更改已查询标题，翻页发送 page=2。
6. 人员资料不伪造人脸已录入，弹窗支持 Escape 关闭。
7. 真实模式监控页面不标为 Mock；门禁执行、照片归档回执缺失时明确显示待接入。

另在成功命令场景中验证断网后保留旧数据、出现连接提示、禁用控制。

## 实机建议检查

- Chrome 100%缩放查看所有页面，390px手机视口检查滚动与按钮。
- 开关灯、设定亮度、风扇与空调操作；确认 pending 期间不可重复提交。
- 有效/无效照片上传与预览；人员新增、搜索和删除。
- 超过20条记录后翻页、编辑时间未查询、无数据区间。
- 真实接口分别返回 pending/acked/failed/timeout，断开服务并恢复。
- 联调 B1–B3 时核对身份结果与门状态、照片预览与存储结果的区别。
