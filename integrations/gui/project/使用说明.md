# v1.2.0 网页＋手机 App 体验版

本轮更新：深绿家居主题、电脑侧边栏、手机底部导航、设备分类（全部/照明/环境/门窗）、设备状态卡片、安装说明与断网页。原有设备确认、历史分页、人员和识别功能继续保留。

## 电脑打开

完整解压，双击“双击打开本地预览.cmd”。需安装 Node.js 22.12+。包内包含 dist，无需重新编译。浏览器本机地址是 localhost/127.0.0.1；启动窗口不要关闭。

## 手机查看网页

开发联调可在项目目录运行 npm ci，然后 npm run dev；手机和电脑连接同一 Wi-Fi，用手机打开终端显示的 Network 地址（例如 http://电脑局域网IP:8001）。若无法访问，请检查网络隔离和本机防火墙，仅允许所需开发端口。双击预览脚本仅监听本机，手机不能使用电脑的127.0.0.1地址。

正式使用由搭档部署 dist 和真实后端，手机访问部署网址。当前提供的是代码包，没有自动部署在线网址。

## 安装到主屏幕

网页包含 manifest、192/512图标及Service Worker。支持的浏览器可能显示“安装应用”，也可使用“手机使用”查看说明。Android Chrome通常从浏览器菜单安装；iPhone Safari通常通过分享→添加到主屏幕。菜单名称与可用性以设备实际显示为准。

需要HTTPS或本机localhost环境。普通局域网HTTP网址可以浏览，但不能据此保证PWA安装。建议正式部署HTTPS后实机验证。这一节描述网页PWA方式。独立安卓APK已另行构建并随交付包提供，见上一级APK目录；未上架应用商店。

## 断网行为

只缓存一个断网提示页，不缓存设备API、人员照片或业务页面。联网首次访问并激活Service Worker后，后续导航断网可显示连接说明。现有页面断网会提示，并拒绝发送设备指令；不提供离线控制，也不排队重放命令。

## 验证范围

类型检查、lint、交互回归和构建已执行。Android APK后续已由用户Windows构建并确认手机测试通过；用户未提供逐项测试记录，网页PWA安装仍未验证。请在自己的Chrome打开后检查首页、底部导航、设备分类、亮度控制和手机安装入口；这些验证不能由DOM测试替代。

参考： https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable

## Windows 打开方式

1. 将整个压缩包解压到普通文件夹，不要在压缩包内直接运行。
2. 双击根目录的“ 双击打开本地预览.cmd ”（实际文件名无首尾空格）。
3. 浏览器自动打开后即可查看。启动窗口不要关闭；关闭窗口即停止服务。
4. 如未自动打开，请复制启动窗口显示的网址到 Chrome。

电脑需已安装 Node.js 22.12 或以上版本。压缩包包含最新 dist，单纯预览无需 npm install，也无需 Python 或后端。不要双击 dist/index.html 打开。

默认是演示模式：不会连接真实摄像头、门禁和风扇，也没有运行 YOLO 或人脸识别模型。

## 建议体验顺序

- 首页：查看房屋动画与设备卡片；点击开灯/关灯，观察等待确认与结果；拖动亮度，再点击“应用亮度”。
- 历史：点击最近24小时；调整时间后点击查询；记录多时使用翻页按钮。
- 人员：新增人员，选择 JPG/PNG/WebP 图片预览；演示模式不保存照片或人脸特征。
- 监控：选择预置图片并开始识别，查看检测框；摄像头页可查看待接入的归档状态。
- 接口测试：供搭档调试使用，技术字段集中保留在这里。

## 已完成的范围

A1–A4：未知/离线状态、命令回执确认、运行模式文案、断连与旧数据提醒。
C1–C6：简化文案、明确动作按钮、亮度草稿与确认、可读性及触屏控件、首页重点、人员照片预览和录入状态区分。
B5：20条/页的设备与识别记录查询、快捷时间范围、已提交筛选条件与编辑条件分离、过期请求响应防覆盖。

B1–B3已预留温控联动、门禁回执和照片归档展示区。没有收到后端结果时明确显示待接入，不伪造通过或保存成功。
B4（门窗时间线、亮度趋势）留待下一阶段；本版保留现有设备历史事件表。

保留第一版的深色风格、二维房屋动画、人员管理、识别预览、空调开关和设定温度操作。空调设定范围目前为16–30°C，联调时按实际硬件能力确认。
