# 开发、重新构建与排错

以下命令均在 CMD 运行。完整解压后，在 project 目录执行；本说明没有假定你的电脑使用 C:\DnB26 路径。

## 环境

- Node.js：建议22系列 >=22.22.2 或24系列 >=24.15.0，兼容包内 jsdom 测试依赖。
- JDK 21；JAVA_HOME 指向JDK安装目录，而非bin。
- Android SDK Platform 35，Build-Tools 35.0.0 和34.0.0，Platform-Tools；建议安装Command-line Tools。
- ANDROID_HOME 指向SDK。常见默认值为 %LOCALAPPDATA%\Android\Sdk。
- Gradle Wrapper 8.11.1 已提供，无需另装全局Gradle。

这次用户用Node24.11.1完成构建，但npm对jsdom等依赖报告EBADENGINE；安装和APK构建成功不代表此旧Node适合运行全部测试，搭档建议使用上面的兼容版本。

## 只看界面

双击 project 中的“ 双击打开本地预览.cmd ”（文件名无首尾空格），使用包内dist，不需npm安装。不要通过双击dist/index.html预览。

## 修改、检查和构建

在 project 中：

```bat
set "npm_config_cache=%LOCALAPPDATA%\npm-cache-dnb26"
npm ci
npm run dev
```

检查（逐条执行；出错时先排错）：

```bat
npm run typecheck
npm run lint
npm test
npm run build
```

模拟模式APK：双击“生成安卓APK.cmd”。脚本默认mock；会安装依赖、构建网页、cap sync和assembleDebug。成功输出：

```text
project/android/app/build/outputs/apk/debug/app-debug.apk
```

脚本在本次交付中增加当前窗口专用缓存默认路径，允许用VITE_DATA_MODE显式指定模式；此调整未在用户Windows上再次执行验证。包内APK仍是用户此前构建的原件。

手动构建（从project开始，逐条执行，失败不继续）：

```bat
set "npm_config_cache=%LOCALAPPDATA%\npm-cache-dnb26"
npm ci
set "VITE_DATA_MODE=mock"
npm run android:sync
set "ANDROID_HOME=%LOCALAPPDATA%\Android\Sdk"
cd android
gradlew.bat assembleDebug --no-daemon
```

## npm缓存权限错误 EPERM

用户原来的自定义D盘缓存报EPERM。使用当前窗口的独立缓存后npm ci成功：

```bat
set "npm_config_cache=%LOCALAPPDATA%\npm-cache-dnb26"
npm ci
```

如仍有文件占用，关闭重复运行的安装/构建进程后再试，保留错误输出。不建议为修复缓存错误直接禁用防护软件。

## Gradle下载慢

本交付版默认官方8.11.1-bin包、networkTimeout=120000。bin不含源码/文档，足够构建。与本机生成APK时使用的本地bin包版本相同。

可用浏览器下载官方ZIP：
https://downloads.gradle.org/distributions/gradle-8.11.1-bin.zip

下载完成后保留ZIP不解压，例如放到 C:\DnB26\gradle-8.11.1-bin.zip；只在本机将 android/gradle/wrapper/gradle-wrapper.properties 的distributionUrl改为：

```properties
distributionUrl=file:///C:/DnB26/gradle-8.11.1-bin.zip
```

重新构建。FileNotFoundException表示该位置没有同名完整文件（检查下载是否完成、是否带(1)、是否放错目录）。共享工程时恢复官方URL，不能把自己电脑的C盘路径当作通用配置。Gradle本体下载完成后，Android依赖仍需联网。

## 签名与分发

当前APK为调试版，适合课程演示。不要共享个人debug.keystore或正式签名私钥；搭档电脑重新构建可能生成不同调试签名，不能保证直接覆盖原APK。卸载重装会清空本地演示数据。正式连续更新需另外约定签名和递增versionCode。

包内可选GitHub Actions配置仅为源码配置，未运行验证；本轮没有上传仓库或发布网址。
