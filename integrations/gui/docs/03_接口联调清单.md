# 搭档接口联调清单

## 优先阅读

1. project/docs/V1_1_INTEGRATION.md：命令回执、B1–B3和分页约定。
2. project/docs/GUI_API_CONTRACT.md：REST、SSE、响应字段。

4. project/src/services/httpDataSource.ts：后端字段/包装适配位置。

## 联调顺序

1. GET /api/system/status 和 /api/dashboard/snapshot：先验证在线、离线、未知、采样时间、快照新鲜度。
2. 传感器历史、设备事件、识别记录：核对ISO UTC时间、page/page_size/total，翻页与无数据状态。
3. 设备命令POST与GET查询：分别验证pending/acked/failed/timeout；只有设备真实确认才返回acked。
4. 人员新增/删除、人脸、YOLO、抓拍与归档：核对图片上传、bbox原图像素坐标和图片URL可达性。严格区分模拟与真实结果。
5. 对齐B1自动温控、B2门禁执行回执、B3照片保存字段；最后接SSE并验证断线恢复。B4另行排期。

## 将安卓切为真实HTTP模式

APK当前内置Mock；接口地址不是安装后自动变更的设置，需要重新构建。

从 project 目录执行，先安装依赖并设置本机JAVA_HOME和ANDROID_HOME。将示例地址替换为后端真实根地址（这里不加/api；适配器已追加/api路径）：

```bat
set "VITE_DATA_MODE=http"
set "VITE_API_BASE_URL=https://your-api-host.example"
npm run android:sync
cd android
gradlew.bat assembleDebug --no-daemon
```

网址仅为占位示例，不是已部署服务。环境变量只对当前CMD及其子进程生效；回到演示版应将VITE_DATA_MODE改回mock并重新同步和构建。

- 手机localhost指手机自己，不能当作开发电脑地址。
- 确认手机与后端网络可达、后端允许WebView实际来源、SSE可连接。
- 优先HTTPS。若课程局域网必须HTTP，Android明文访问策略需另行检查并限定范围，当前包不承诺HTTP可直接访问。
- 图片URL必须能由手机直接访问；勿返回仅后端本机可访问的路径。
- 字段若沿用{code,data}包装，在httpDataSource.ts统一解包；不要在各页面分散适配。

真实硬件、模型准确率、后端数据库和照片落盘均不在本次GUI实测结论中。
